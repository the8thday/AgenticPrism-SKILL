## Implemented scope and model limits

- Shared cancellation-free P+L equilibrium primitive, opt-in declared/fitted
  active Pt, a nuisance-Pt KD profile, and operational Pt/KD diagnostics.
- SET n-curve shared KD with separate signal parameters and known sourced
  constant species; conservative koff or measured-time equilibration gate.
- Separate cell-binding specialist: apparent KD, joint total/control slope,
  explicit background, relative or unweighted objective, receptor conversion
  to M, independent-experiment log summaries and assay gates.
- Exact mutually exclusive three-state competition Ki; guarded optional
  Cheng–Prusoff diagnostic. Four-state is not implemented.
- Opt-in independent-cycle SPR/BLI plateau-window Req and hyperbolic KD_ss;
  kinetic fraction ≥95% at both window start and association end, or a declared
  ≤5% flatness proxy when rates are unreportable. No averaging of KD estimates.
- Facts are extracted from saved equilibrium and cell results, without refit.

Runtime numerics are Python. Profile-F is approximate, conditional on supplied
concentrations and assay model. Cell apparent KD is not intrinsic affinity.
Fitted Pt/KD thresholds do not reliably classify the true titration regime near
its decision boundary; the registered withholding misses below are mandatory
runtime disclosures. Passing an optimizer does not validate the assay.

## Deviations and execution details

- Literal whole-manifest byte identity is incompatible with truthful release
  provenance: package version, code hashes and creation time change. The legacy
  check therefore compares all prior hashed scientific CSV/JSON/text bytes,
  permits only the added equilibrium facts file, and retains current manifest
  metadata. HTML embeds current manifest provenance, so whole HTML/PDF/PNG bytes
  are not claimed identical across releases. No existing `runs/` was modified.
- The common competition primitive and fitter branch landed with phase 1 because
  all opt-in models share the engine; phase 3 separately committed the competition
  contract and fixtures. Four-state was omitted as explicitly permitted.
- Calibration withholding used the narrower diagnostic-specific definition above;
  all-withholding counts are disclosed without changing registered outcomes.
- Claude authentication failed; available independent Codex agents replace that
  live harness for this release, with original failures retained.
- SET supports declared sourced constant concentrations, not fitted per-curve
  active fractions. Steady-state is scoped to independent cycles. Neither
  restriction changes a legacy default.

## Independent review fixes (2026-09-29)

A review after the checks above (by the assistant that wrote the 0.11.0
instruction, not the implementer) found three scientific gaps and a calibration
design issue. All fixes are gates, declarations or non-blocking disclosures; none
changes the fitting objective, profile or reportability rule.

- **SET valency and readout.** `valency` is now required for
  `solution_equilibrium_titration` (and refused for other models): constant
  species monovalent/bivalent, detected signal `free_sites` or
  `molecules_with_any_free_site`, constant and titrant concentration bases, and
  source. A bivalent constant species (IgG) captured as molecules with any free
  site is refused, because that signal is not proportional to the free-site
  fraction and no bivalent SET model is implemented. A bivalent species with a
  free-site readout in site concentrations runs with a must_mention disclosure.
- **Cell control baseline.** `nonspecific.baseline` (`shared`/`separate`) is
  declared. Antigen-negative control cells must use `separate`, one extra control
  intercept per curve with the nonspecific slope still shared. New fixture
  `config_cell_antigen_negative.json`; R agreement above; no coverage study.
- **Steady-state Rmax.** Plateau extraction now requires `fit.rmax=shared`;
  per-curve Rmax means sensor plateaus are not on one scale.
- **Titration-span design warning.** `design_warnings` records
  `titrant_max_below_twice_constant_species` (operational factor 2) for
  depletion, SET and quadratic cell fits. It is copied into facts and
  must_mention and never changes reportability.
- Minor: the legacy total-concentration refusal now points to
  `one_site_depletion`; the benchmark script accepts `--output` (it previously ran
  and rewrote its record on any invocation); the affinity HTML report leads with a
  results table (point values only for reportable fits) instead of raw JSON.

**Registered results unchanged.** 56 draws (four per calibration scenario,
including SET and cell) were recomputed with the fixed code and matched the
committed calibration record exactly in estimate, interval, coverage and
withholding. No calibration was rerun and no registered row changed.
