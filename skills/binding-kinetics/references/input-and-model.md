# Canonical sensorgram contract

The input CSV needs `fit_group_id,sample_id,experiment_id,curve_id,time,time_unit,response,response_unit,concentration,concentration_unit,phase,association_start,dissociation_start`. Optional `observation_id`, `reference_response`, `blank_response`, `blank_reference_response`, `exclude`, and `exclusion_reason` retain traceability. `time_unit` is `s` or `min`; concentration units follow the equilibrium module's explicit molar unit table. Each curve must have strictly increasing times and consistent metadata. Phases must exactly match declared boundaries: baseline before association start, association until dissociation start, then dissociation. A fit group cannot pool different samples or independent experiments. Use a positive analyte concentration on each curve, with at least two distinct concentrations per fit group (single-cycle curves: per injection step, below).

Configuration starts from [synthetic example](../../../fixtures/kinetics_synthetic/config.json). `analysis_type` is `binding_kinetics`. `assay.one_to_one_supported` and `concentration_known` must be true with a specific rationale; `independent_cycles` must be true for the default `injection_design=multi_cycle` and false for `single_cycle` (below). `column_map` maps source headings to canonical names. `preprocessing.reference_mode=reference_column` subtracts an exact-row reference (`double_reference`: below); `baseline_subtraction=baseline_mean` subtracts the mean of included baseline observations. Neither action occurs by default. `stride` samples the declared time course before fitting. Fit-window skips and dissociation duration are seconds. Record any exclusion with a reason; no automatic smoothing or outlier removal occurs.

The ideal model is `dR/dt = kon*C*(Rmax-R) - koff*R` during association, with C set to zero for dissociation while the row's nominal analyte concentration remains recorded. The association begins at modeled zero occupancy; configure the offset separately. `kon` and `koff` are shared within a fit group. `fit.rmax` is `per_curve` or `shared`; `fit.offset` is `fixed_zero` or `fitted_per_curve`. Use `fitted_per_curve` when the baseline has not been physically zeroed and that nuisance parameter is identifiable. Current objective is unweighted response-scale least squares.

Joint moving-block bootstrap resamples residuals separately within each curve and phase, refits both rates, and computes each KD as the paired `koff/kon`; it does not divide marginal CI endpoints. Set `uncertainty.method=none` only when intervals are intentionally omitted. Bootstrap intervals are conditional on preprocessing, fit windows, model, and chosen block length. Residual autocorrelation and material changes across defensible fit windows call for review, not an automatic mechanism diagnosis. A rate pinned to its numerical bound or a rank-deficient rate Jacobian is withheld. A reportable estimate with warnings remains model-conditional.

An instrument's nominal concentration, regeneration history, ligand loading, sensor/channel, valency, temperature, transport conditions and subtraction method should be retained in the source record when available. Rebinding, mass transport, avidity and heterogeneous surfaces require a different validated model. Endpoint equilibrium KD and kinetic KD are different estimands.

## Single-cycle series and double referencing (0.7.0)

Set `assay.injection_design="single_cycle"` and `assay.independent_cycles=false` for a curve built from sequential injections on one surface without regeneration. Each row carries the `association_start`, `dissociation_start` and `concentration` of **its own** injection step; baseline rows (before the first injection) carry the first step's values. The loader rebuilds the ordered steps per curve and requires: ≥2 steps with distinct concentrations, `association < dissociation ≤ next association`, and phases that exactly follow from time (association inside a step's injection window, dissociation until the next injection). See the [single-cycle example](../../../fixtures/kinetics_single_cycle/config.json).

Model: within step k, `R(t) = Req_k + (R_start − Req_k)·exp(−(kon·C_k + koff)(t − a_k))` with `Req_k = kon·C_k/(kon·C_k + koff)`; between injections and after the last one, `R` decays as `exp(−koff·Δt)`. The state at each boundary is carried into the next step, starting from zero at the first injection; Rmax (and optional offset) remain linear nuisance parameters. Bootstrap blocks are resampled within each association or dissociation segment, so short intermediate dissociations can make a block length infeasible (`insufficient_points_for_block_length`). Window sensitivity shortens only the final dissociation. `dissociation_duration_s` applies to every dissociation segment. Single-step curves reproduce the multi-cycle model exactly.

`preprocessing.reference_mode="double_reference"` requires `reference_response`, `blank_response` and `blank_reference_response` columns on the same rows (same times) and uses `(response − reference_response) − (blank_response − blank_reference_response)`. The blank is a buffer-only cycle run in the same way (a buffer single-cycle series for single-cycle data). Errors in the subtracted traces are not propagated separately (`reference_uncertainty_not_separately_propagated`). The Octet importer accepts `reference_file`, `blank_file` and `blank_reference_file` per trace (all three needed for double referencing) with exactly matching times and carries them as these columns; it never subtracts anything itself.
