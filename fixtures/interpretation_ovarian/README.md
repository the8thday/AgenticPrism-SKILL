# Published ovarian log-rank example

The first two-sample example in the R `survival::survdiff` documentation is
`survdiff(Surv(futime, fustat) ~ rx, data=ovarian)`. Its companion Cox score
identity is checked independently. Sources, versions and hashes are in
`provenance.json`; `reference.csv` is regenerated by R, not a hand-entered target.

Run `scripts/prepare_interpretation_fixtures.py` to recreate the data/reference
exports and `scripts/validate_interpretation_benchmarks.py` to reproduce and
compare the worked example, including its facts artifact. The latter checks
the exported dataset, R help text and reference hashes before comparison.

The KM and Efron Cox results supplied by the normal workflow are supplementary;
the published worked-example claim covers the log-rank test only. This human
ovarian-cancer dataset is a numerical benchmark, not an antibody animal study.
The config's time origin/censoring text is a reproduction declaration, not a
validated clinical protocol. The installed R survival package declares LGPL (>= 2); no separate
data-license or ownership claim is made here.
