# Regression and GLM fixtures

Synthetic workflows are generated by `scripts/prepare_regression_0135_fixtures.py`
with seed 131350101. They cover factors/interactions, heteroscedasticity, grouped
binomial denominators, count exposure/log offsets, overdispersion, missingness,
rank deficiency, separation and out-of-support predictions. They are not drug
efficacy or method-validation evidence.

`star98_public.csv` comes from the statsmodels 0.15.0 distributed Star98 dataset,
with attribution and SHA-256 in `source_manifest.json`. It is the official GLM
worked example using data distributed with permission from Jeff Gill (2000).
Source predictors (including precomputed interactions) are retained; outcome
is NABOVE and trials is NABOVE+NBELOW. IDs are explicit county row identifiers.
It is numerical reference evidence only. The fixed-binomial uncertainty is
withheld because the extra-binomial dispersion diagnostic fails.
